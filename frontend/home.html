How to use

🔍 Codebase Agent

01
Enter a repo — type any public GitHub repo in owner/repo format, e.g. fastapi/fastapi
02
Ask your question — ask about architecture, specific files, how a feature works, or anything about the codebase
03
Watch it work — the agent browses files and searches code in real time, streaming its answer as it goes
04
Follow up — keep asking questions about the same repo without re-entering it

📄 Doc Chat

01
Upload a PDF — drag and drop or click to upload. Max file size is 10MB
02
Wait for indexing — the document is chunked and embedded, ready to search in a few seconds
03
Ask questions — ask anything about the document. Answers come strictly from the PDF content
04
Clear when done — hit ✕ clear to remove the session and upload a new document
